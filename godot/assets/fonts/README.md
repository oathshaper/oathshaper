# Interface typeface

Libre Baskerville is bundled for Oathshaper's wordmark, card titles and display headings so they do not fall back to a different system serif on another platform. Body text and controller symbols use Godot's default UI face.

- Authors: The Libre Baskerville Project Authors / Impallari Type.
- Source: https://github.com/impallari/Libre-Baskerville/tree/d20160cfa0ac4c532327f85b3ca4054acf92ed38
- Upstream file: `fonts/variable/LibreBaskerville[wght].ttf`; local filename shortened only. Font bytes are unmodified.
