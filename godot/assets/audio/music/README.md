# Lantern Quay music

`lantern_quay.ogg` is the user's selected clarity version of the locally generated ACE-Step harbor instrumental. It plays continuously through the title, quay, office and combat. The Music slider controls it independently; spoken dialogue lowers it by another 8 dB.

The 30-second source has a 1.5-second wrap crossfade, producing a 28.5-second loop. It is stereo, 48 kHz, Vorbis quality 7. The source was matched to −20.01 LUFS before the loop conversion. No generation model or service is needed to play it.

[Provenance](provenance.json) records the prompt, seed, pinned model/code revisions, source hashes and final asset hash. This is generated music, separate from the CC0 effects and field recordings. No reference recording was used. The repository license is unchanged.
