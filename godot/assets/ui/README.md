# UI provenance

Current distribution status: the [2026-11-03 Meshy rights review](../meshes/README.md) supersedes earlier provisional Meshy-permission caveats in these import notes. The owner confirmed paid/private generation; official terms permit distribution of that output. Third-party notices remain applicable.

`player-portrait.png` is an unchanged copy of `art/concepts/player-meshy-reference.png`, an original OpenAI-generated Oathshaper concept from 2026-10-20. See [concept provenance](../../../art/concepts/README.md) and recorded prompts. It is separate from the Meshy model. No BioWare art was used.

The title uses the bundled Libre Baskerville font. Its source, checksum and SIL Open Font License are recorded in [the font provenance](../fonts/README.md).

`lantern-garden.png` is a HUD-free Godot capture of the project's existing imported Seaside Garden and quay, rendered by `godot/tools/capture_menu_garden.gd` on 2026-10-22. No external illustration was substituted. It inherits the underlying scene assets' provenance and unresolved redistribution review; see the meshes README. The launcher adds its gradient and captions as ordinary Godot controls.
